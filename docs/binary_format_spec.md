# 📑 Formal Specification of the Flash ROM Synaptic Format (`.rodata`)

This document formally specifies the standardized binary format for immutable synaptic and neuronal structures generated by the `snn_compiler` AOT toolchain for the `snn_core` runtime engine.

---

## 🎯 Architectural Design Goals

1. **Zero Flash $\to$ SRAM Copy**: Synaptic tables must execute directly in place (`XIP` — eXecute-In-Place) from Flash ROM (`.rodata`).
2. **Maximum Compactness**: Storage footprint in Flash is minimized through 16-bit indexing (`u16`) and shared-scale INT8 quantization.
3. **Strict Memory Alignment**: All memory accesses are naturally aligned (2 bytes for `u16`, 4 bytes for `i32` and pointer words) to prevent unaligned access penalties on ARM Cortex-M and RISC-V.

---

## 📊 1. Flash ROM CSR Memory Model

A sparse synaptic layer connecting $N_{\text{in}}$ afferent neurons to $N_{\text{out}}$ target neurons with $S$ non-zero synapses is stored in Compressed Sparse Row (CSR) format:

```text
+-----------------------------------------------------------+
| row_ptrs: [u16; N_in + 1]                                 | (2 * (N_in + 1) bytes)
| Indexing offsets into targets and weights tables          |
+-----------------------------------------------------------+
| targets:  [u16; S]                                        | (2 * S bytes)
| Indices of target post-synaptic neurons (0..N_out-1)      |
+-----------------------------------------------------------+
| weights:  [Weight; S]                                     | (Fix32 or INT8 format)
| Synaptic weight values                                    |
+-----------------------------------------------------------+
```

### Supported Weight Formats

| Weight Format | Size per Synapse | Physical Representation | Decoding Formula |
| :--- | :--- | :--- | :--- |
| **Fix32** | 4 bytes | Signed `i32` Q16.16 | $w = \text{raw} / 65536.0$ |
| **Fix16** | 2 bytes | Signed `i16` Q8.8 | $w = \text{raw} / 256.0$ |
| **Quantized INT8** | 1 byte | Signed `i8` with shared Fix32 `scale` | $w_i = \text{scale} \times \text{raw}_i$ |

---

## 🧮 2. Flash and SRAM Memory Footprint Formulas

### Flash ROM Footprint (Per Layer)

For a layer with $N_{\text{in}}$ inputs and $S$ synapses:

$$\text{Flash}_{\text{Fix32}} = 2 \times (N_{\text{in}} + 1) + 2 \times S + 4 \times S = 2(N_{\text{in}} + 1) + 6S \text{ bytes}$$

$$\text{Flash}_{\text{INT8}} = 2 \times (N_{\text{in}} + 1) + 2 \times S + 1 \times S + 4 (\text{scale}) = 2(N_{\text{in}} + 1) + 3S + 4 \text{ bytes}$$

> [!TIP]
> For a typical 100,000-synapse model quantized to INT8, total Flash consumption is only **~300 KB**, allowing deployment even on microcontrollers with modest Flash capacity (512 KB).

### SRAM Footprint (ActivationArena)

For a network of $L$ layers with $N_{\text{total}} = \sum N_l$, $N_{\max} = \max(N_l)$, and $W_{\max} = \lceil N_{\max} / 32 \rceil$:

$$\text{SRAM}_{\text{total}} = 4 \times N_{\text{total}} + \text{align}_4(N_{\text{total}}) + 4 \times N_{\max} + 8 \times W_{\max} \text{ bytes}$$

| SRAM Component | Architectural Role | Size |
| :--- | :--- | :--- |
| $V_{\text{mem}}$ | Persistent membrane potentials | $4 \times N_{\text{total}}$ bytes |
| Refractory | Refractory state counters (1B/neuron) | $\text{align}_4(N_{\text{total}})$ bytes |
| Accumulators | Shared synaptic accumulation buffer | $4 \times N_{\max}$ bytes |
| Ping-Pong Spikes | Double-buffered inter-layer spike words | $2 \times (4 \times W_{\max})$ bytes |

## 🔒 3. Safety Invariants and Validation Constraints

Every binary Flash ROM CSR table must satisfy the following invariants to ensure the total absence of runtime panics during inference:

1. **Pointer Monotonicity**:
   $$\forall i \in [0, N_{\text{in}} - 1], \quad \text{row\_ptrs}[i] \le \text{row\_ptrs}[i+1]$$
2. **Synaptic Boundary**:
   $$\text{row\_ptrs}[N_{\text{in}}] = S \quad \text{and} \quad \forall i, \; \text{row\_ptrs}[i] \le S$$
3. **Target Index Validity**:
   $$\forall k \in [0, S - 1], \quad \text{targets}[k] < N_{\text{out}}$$
4. **SRAM Arena 4-Byte Alignment**:
   $$(\text{arena\_ptr} \pmod 4) = 0$$

The `snn_compiler` AOT toolchain formally verifies these 4 invariants during the code generation pass.
